# 本机 Codex 辅助写作

桌面端文章编辑器右上角的星光按钮打开“本机 AI 写作”。支持起草、润色、续写和摘要，可填写额外要求、编辑生成结果，再选择替换正文、追加正文或采用为摘要。采用后仍需手动保存文章。

在运行 Flutter 的同一设备安装 Codex CLI，先在终端完成 `codex login`，并用 `codex login status` 检查登录状态。默认从应用进程的 PATH 查找 `codex`；桌面启动器的 PATH 不同时，可在对话框填写可执行文件绝对路径。使用现有 Codex 模型及服务配置，不需要在 WindBlog 后端保存密钥。

此功能是本机 CLI 调用，不是离线模型。标题、正文和写作要求会发送给 Codex 配置的模型服务。调用在临时工作目录中运行，使用只读沙箱、禁止交互审批和临时会话，通过标准输入传入文本，结果经临时文件读取后删除。关闭对话框会取消任务，超过三分钟会超时。不会自动保存或发布文章。

支持 Linux、macOS 和 Windows 桌面。Windows 需要能直接启动的 Codex 可执行文件；本功能不通过 shell 执行 `.cmd` 包装器。Web 浏览器、Android 和 iOS 显示平台限制，不会转而调用服务器上的 Codex。

本机真实调用检查：在 Flutter 项目目录运行 `dart run tool/local_codex_smoke.dart`。它会发送一条简短中文润色请求并打印结果。自动测试使用假的 CLI，不消耗模型额度。

## 模型和高级提示词

“模型”默认跟随 Codex 配置；下拉列表读取当前设备 `$CODEX_HOME/models_cache.json`（未设置时为用户目录下 `.codex/models_cache.json`）。缓存为空时仍可选择自定义模型 ID。选择模型后通过 `--model` 传给 CLI，不修改 Codex 全局配置；缓存列表不保证账号有访问权限。

展开“高级选项 · 自定义提示词”，开启开关后可替换完整默认模板。支持 `{{task}}`、`{{requirements}}`、`{{title}}`、`{{content}}`、`{{format}}`、`{{output_rules}}`，只替换一次，不会把正文中的同名变量再次展开。自定义模板只包含明确引用的文章信息。可一键恢复默认模板；关闭开关即使用默认提示词。写作任务仍决定采用结果时替换正文、追加正文还是写入摘要。
